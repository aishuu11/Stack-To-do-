# Byte-Sized To-Dos

A simple to-do list app built as my first solo project. It helps me practise Python and Streamlit while learning how to plan, build, and track a project.

## Features

- Add tasks
- View tasks 
- Delete a task 
- Validate input 

## Built With (tech stack)

- Python
- Streamlit
- JSON for local task storage
